abstract: 'Windex is a scalable 5G scheduler that gives each user guarantees on throughput and service regularity. It uses neural networks to compute a Whittle index per user and allocates resources in order of these indices, turning a combinatorial problem into a linear one. Running on a real-time RIC, it makes decisions in under 20 μs per user and significantly improves service guarantees over existing schedulers.'
